# 自举规约

自举智能体应先读取根清单与 `knowledge-wiki-maintenance` 的四件套，确认目标工作区、目标宿主的技能发现路径和用户授权范围。能力域的 `AGENTS.md` 是源 vault `CLAUDE.md` 规则的 canonical 迁移版本。

1. 将 `wiki-ingest`、`wiki-query`、`wiki-lint` 作为**完整目录**安装到当前宿主的技能发现路径。
2. 将 `llm-wiki-vault` 资产目录的内容复制到目标工作区根目录。目标已有同路径内容而且不同，必须报告冲突；不得静默覆盖。
3. `raw/` 是不可变事实层：运行期间不得编辑或删除其中的源文件文本。`wiki/` 才是可编译、可写的知识输出层；`assets/` 是媒体层。
4. 不生成 MCP 配置或环境文件：本包未声明这些资产。
5. 完成后进行四层验收：根/子清单静态检查、宿主产物检查、安装状态检查，以及能力身份/三个技能/工作区资产的宿主原生发现验证。

不得把 `.obsidian` 运行状态、编辑器缓存、用户绝对路径、会话、日志或本地私有资料回写到 canonical 包。不得仅因文件已复制就报告自举成功。
